System Architecture

DrizzleOS Multi-Tenant Architecture

Tenant Aktif: TNT-DRIZZLE-SOLO-01 (Drizzle Project Studio Solo HQ).

Fitur Arsitektur Multi-Tenant:

  • Relational DB Sandbox: 6 koleksi relasional terisolasi (Services, Customers, Orders, Materials, PurchaseOrders, FinanceLedger).
  • Mandatory 1:1 Packaging Engine: Alokasi kemasan otomatis 1:1 per unit apparel/merchandise di kalkulasi Material Requirements Planning (MRP).
  • Integrated Production Workflow: State machine 5 tahap (DESIGN → PRINTING → SEWING → QC → SHIPPED).
  • Finance & HPP Ledger: Pencatatan kas masuk termin DP 50%, pelunasan, pengeluaran vendor makloon, dan margin laba bersih otomatis.
